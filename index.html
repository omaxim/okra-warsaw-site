How close does the model get to real certificates?

The buildings with a certificate were part of the model's training, so comparing the map against them would flatter it. Instead, Warsaw was cut into 2 km blocks and each block predicted by a model trained without it; the other seven cities stayed in training throughout. Below, one plot per indicator: each column is a band of certificate values, and every certified building in it adds its whole out-of-fold posterior — the model's spread of likely values, not one number — up the column. The shading is shared across the whole plot, so it shows both where the model puts each band and where most of the buildings are. The dashed line is perfect agreement; hover for the numbers.

Spatial 5-fold cross-validation of the same pipeline (fussade, pl-pool → Warsaw, 2026-10-06); each posterior enters as a log-normal with the CV's median and 10–90 % interval; certificate: the register median per building. The model does not yet make real use of the orthophotos or the Mapillary facades; on this evidence the photos add nothing measurable so far.
